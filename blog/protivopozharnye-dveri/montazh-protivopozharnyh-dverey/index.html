Монтаж противопожарных дверей

Монтаж противопожарных дверей — лицензируемая деятельность: работы выполняет организация с лицензией МЧС. Зазоры заполняют негорючими материалами, крепление — по инструкции производителя; по итогам оформляется акт.

Черновик по ТЗ: структура H2–H3 и тезисы утверждены, текст пишет автор с экспертом GEKARD. Эксперт: технолог GEKARD · обновлено 2026-09-24
