Противопожарные двери для склада

Класс двери склада определяется категорией помещения по взрывопожарной и пожарной опасности и типом противопожарной преграды — часто EI60. Для прохода с тележками нужны двустворчатые двери; для проезда техники — ворота.

Черновик по ТЗ: структура H2–H3 и тезисы утверждены, текст пишет автор с экспертом GEKARD. Эксперт: технолог GEKARD · обновлено 2026-09-24

ТЗ статьи для автора (видно только на staging)

Задача: Подобрать противопожарные двери для складского помещения
Аудитория / этап: проектировщики, снабженцы, подрядчики / выбор
Объём: 4000–6000 зн.
Границы: Склады; ТЦ — A111, двустворчатые — A117

Термины и ошибки: категория помещения, противопожарная преграда; ошибка — занижать класс

Собственная польза: Максимальные размеры двустворчатых дверей GEKARD (до 2400×1900) и варианты — уточнить ориентацию размеров у технолога

Медиа:

  • Фото двустворчатой двери склада
  • Таблица категория → класс двери

Проверить факты:

  • СП 12.13130 категории
  • Требования СП 4.13130 к складам
