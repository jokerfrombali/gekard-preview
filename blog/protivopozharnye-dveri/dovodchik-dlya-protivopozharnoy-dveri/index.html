Доводчик для противопожарной двери

Противопожарная дверь должна закрываться самостоятельно, поэтому доводчик — обязательный элемент. Подбирают его по массе и ширине полотна; доводчик должен быть сертифицирован для противопожарных дверей.

Черновик по ТЗ: структура H2–H3 и тезисы утверждены, текст пишет автор с экспертом GEKARD. Эксперт: технолог GEKARD · обновлено 2026-09-24

ТЗ статьи для автора (видно только на staging)

Задача: Понять требования к доводчику и выбрать его
Аудитория / этап: УК, эксплуатация, ответственные за пожарную безопасность, подрядчики / выбор
Объём: 5000–10000 зн.
Границы: Доводчик; координатор — A120, антипаника — A119

Термины и ошибки: усилие закрывания EN, электромагнитный удержатель; ошибка — доводчик с фиксацией

Собственная польза: Комплектация доводчиков GEKARD по моделям — запросить

Медиа:

  • Схема регулировки доводчика
  • Таблица масса → класс доводчика

Проверить факты:

  • ППР (Постановление 1479): требования к эксплуатации противопожарных дверей
  • ГОСТ Р 56177 — доводчики
