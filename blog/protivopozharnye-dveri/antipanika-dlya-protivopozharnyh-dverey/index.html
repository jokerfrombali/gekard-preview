Система антипаника для противопожарных дверей

Антипаника позволяет открыть дверь по ходу эвакуации нажатием на штангу без ключа. Применяется на эвакуационных выходах из помещений с массовым пребыванием людей; ставить нужно устройство, сертифицированное для противопожарных дверей.

Черновик по ТЗ: структура H2–H3 и тезисы утверждены, текст пишет автор с экспертом GEKARD. Эксперт: технолог GEKARD · обновлено 2026-09-24
