Технические двери для производственных помещений

Для цехов выбирают металлические двери усиленного исполнения с износостойким покрытием и фурнитурой под частое использование. Если между помещениями разные категории пожарной опасности, проект может требовать противопожарную дверь. Разбираем, какие исполнения подходят для каких зон производства.

Черновик по ТЗ: структура H2–H3 и тезисы утверждены, текст пишет автор с экспертом GEKARD. Эксперт: технолог GEKARD · обновлено 2026-09-24

ТЗ статьи для автора (видно только на staging)

Задача: Выбрать дверь для цеха с учётом нагрузок, габаритов, требований проекта
Аудитория / этап: главные инженеры, снабженцы производств / выбор
Объём: 2500–7500 зн.
Границы: Производство; склад — A208; противопожарные двери — в другом хабе

Термины и ошибки: категория помещения, эвакуационный выход, нестандартный проём; ошибка — не учесть категорию помещения

Собственная польза: Кейсы поставок GEKARD на производства (только подтверждённые, запросить); работа по 44-ФЗ/223-ФЗ

Медиа:

  • Фото двустворчатой двери в цех
  • Таблица: зона производства — исполнение двери
  • Схема габаритов двустворчатой двери

Проверить факты:

  • Требования СП 4.13130 к дверям между помещениями разных категорий
  • Участие GEKARD в закупках 44-ФЗ/223-ФЗ
