Уличная техническая металлическая дверь

Для улицы дверь должна выдерживать осадки, мороз и перепады температур: нужны стойкое покрытие, уплотнение, защита замка и, при тёплом помещении, утепление с терморазрывом. Большинство проблем уличных дверей — от монтажа и отсутствия козырька. Составили чек-лист.

Черновик по ТЗ: структура H2–H3 и тезисы утверждены, текст пишет автор с экспертом GEKARD. Эксперт: технолог GEKARD · обновлено 2026-09-24

ТЗ статьи для автора (видно только на staging)

Задача: Подобрать дверь для установки на улице с учётом осадков, мороза, коррозии
Аудитория / этап: УК, частные заказчики, подрядчики / выбор
Объём: 2000–2500 зн.
Границы: Комплекс уличных условий; утепление — A204, покрытие — A214

Термины и ошибки: козырёк, отлив, пароизоляция; ошибка — отсутствие защиты монтажного шва

Собственная польза: Рекомендации GEKARD по уличному монтажу (запросить); фото уличных объектов

Медиа:

  • Чек-лист уличной двери
  • Схема монтажного узла уличной двери
  • Фото двери с козырьком

Проверить факты:

  • Рекомендации по монтажному шву (ГОСТ 30971 применимость проверить)
  • Уличные исполнения GEKARD
