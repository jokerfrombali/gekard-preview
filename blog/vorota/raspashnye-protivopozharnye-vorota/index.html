Распашные противопожарные ворота

Распашные противопожарные ворота — самый простой тип: две створки на петлях, доводчики и координатор закрывания. Они подходят для проёмов, перед которыми есть место для разворота створок. Для самозакрывания при пожаре створки держат открытыми электромагнитами, которые отключаются по сигналу.

Черновик по ТЗ: структура H2–H3 и тезисы утверждены, текст пишет автор с экспертом GEKARD. Эксперт: технолог GEKARD · обновлено 2026-09-24

ТЗ статьи для автора (видно только на staging)

Задача: Решить, подойдут ли распашные противопожарные ворота и как обеспечить их закрытие
Аудитория / этап: снабженцы, проектировщики, эксплуатация / выбор
Объём: 2000–5000 зн.
Границы: Распашные противопожарные; обычные металлические распашные — A410, откатные — A403

Термины и ошибки: координатор закрывания, притвор, электромагнитный удержатель; ошибка — ворота без координатора, створки не закрываются полностью

Собственная польза: Фото производства створок и узлов петель — запросить у GEKARD, если есть серия ворот

Медиа:

  • Схема радиусов открывания створок
  • Узел притвора с лентой
  • Фото ворот с калиткой

Проверить факты:

  • Наличие ворот в ассортименте GEKARD (на gekard.ru ворота не найдены) — подтвердить у заказчика
  • Требование к самозакрыванию противопожарных ворот (ФЗ-123 / СП 4.13130)
  • Допустимость калитки без потери класса по сертификату
