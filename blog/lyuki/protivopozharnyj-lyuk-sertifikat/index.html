Документы на противопожарный люк

С противопожарным люком поставляются сертификат соответствия, паспорт изделия и маркировка на коробке. Без них люк не примут при сдаче объекта и проверке.

Черновик по ТЗ: структура H2–H3 и тезисы утверждены, текст пишет автор с экспертом GEKARD. Эксперт: технолог GEKARD · обновлено 2026-09-24

ТЗ статьи для автора (видно только на staging)

Задача: Проверить комплект документов при закупке люка
Аудитория / этап: снабженцы, проектировщики, заказчики по 44-ФЗ / покупка
Объём: 6000-8000 зн.
Границы: Только документы; классы — A302

Термины и ошибки: сертификат соответствия, паспорт, лицензия МЧС; ошибка — сертификат на другую модель

Собственная польза: Запросить у GEKARD образец паспорта и сертификата на люк

Медиа:

  • Фото маркировочной таблички
  • Чек-лист документов при приёмке

Проверить факты:

  • Требования к сертификации по ФЗ-123 ст. 145
  • Лицензирование монтажа — Постановление Правительства №1128
  • Ассортимент люков GEKARD на сайте не найден — подтвердить у заказчика наличие и характеристики
